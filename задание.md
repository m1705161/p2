# Практическая №2 — спроектируй архитектуру данных под задачу

**Срок:** 2 недели.
**Оценка:** 20 баллов. 
**Защиты и очной проверки нет** — преподаватель смотрит твою архитектуру и то, что в коде и в Docker.

---

## 1. Идея

За вторую часть курса ты разобрал блоки платформы данных по отдельности:

| Тема | Что умеешь |
|---|---|
| SCD | Type 1 / Type 2 / Type 3 / Type 6 — когда и какой выбирать |
| CDC | Debezium → Kafka, захват изменений и материализация SCD в Lakehouse |
| Streaming vs Batch | архитектуры Lambda и Kappa, event-time, водяные знаки |
| SCD Type 2 на CDC-потоке | практика (лаба) |
| RAG | 5 стадий: ingestion → chunking → embedding → поиск → генерация |
| Векторные БД | эмбеддинги, выбор индексов, гибридный поиск |
| Feature Store | признаки для ML, consistency между обучением и инференсом |

Цель практической — соединить это в одну архитектуру под конкретную задачу.

## 2. Твой вариант

Вариант назначает преподаватель (смотри [таблицу распределения вариантов](https://docs.google.com/spreadsheets/d/17DlzuG1euPQ4nVzaXLXWGY_9bzg0CHlyhdeF-FPg_Zo/edit?usp=sharing)). Полные описания — в `варианты.md`:

| # | Тема | Одной фразой |
|---|---|---|
| 1 | CDC → SCD → Lakehouse | захватить изменения справочника и материализовать историю |
| 2 | Streaming vs Batch | обработать поток событий без потерь и задвоений |
| 3 | RAG + векторная БД | отвечать по содержимому документов |
| 4 (доп)| Feature Store *(на выбор)* | признаки для ML без рассинхрона обучение/инференс |
| 5 (доп)| Все темы в одной архитектуре *(на выбор)* | собрать варианты 1–4 в единую схему |

Работаешь с тем вариантом, который тебе ближе всего; вариант 5 — хардкор.

## 3. Что сдаёшь

Репозиторий на **GitHub под своей учётной записью**:

```
├── architecture.drawio   # схема (исходник) — обязателен
├── отчет.md              # заполненная форма
├── docker-compose.yml    # (допустимо несколько)
└── (скрипты, SQL, конфиги, скриншоты можно но не влияют на оценку)
```

Списывание недопустимо под копирку, одинаковые схемы недопустимы. 
Оценивается не умение работать с моделью, а знания полученные на лекциях.
Схемы, сделанные самостоятельно, будут оценены выше, чем схемы с нейросетью.
